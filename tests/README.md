# Test material

Files here contain embedded test examples, generated fixtures and intentionally malformed inputs. Named characters, dates and identifiers in a test input are not research observations or claims about real people. Email examples use reserved `.invalid` domains; temporary tests create their own keys and stores.

The two standalone demonstration transcripts are under `examples/synthetic/`. No operational journal, private register, interview collection or model weights are distributed here.

Historical comments and expected-failure labels describe earlier development stages. For the current measured scope use [Testing](../docs/TESTING.md), [Contract scope](../docs/CONTRACT-SCOPE.md) and [Attack-test mapping](../docs/ATTACK-TEST-MAPPING.md).
