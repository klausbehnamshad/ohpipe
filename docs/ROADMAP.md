# Roadmap

Next work addresses concrete gaps:

- Resolve historical contract tests against supported interfaces while preserving their substantive requirements.
- Generalize the manual workflow's closed profile bindings and document a synthetic setup independent of a named pilot.
- Improve English diagnostics and recovery guidance.
- Expand installation checks across Python versions and POSIX environments.
- Evaluate model behavior on suitable, separately documented reference material.

No completion date is promised. Automatic identification quality, general legal compliance, unattended interpretation and universal export suitability are not claimed by this preview.
