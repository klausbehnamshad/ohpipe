# Reporting a security issue

Do not put transcripts, identifying examples, private configuration, credentials or keys into public issues or pull requests.

Use GitHub private vulnerability reporting if enabled for this repository. If no private route is available, open a minimal issue requesting a private contact route without disclosing the vulnerability or sensitive material.

Identify the affected version or commit and describe the behavior using invented material. Include a minimal synthetic reproduction where possible.

This experimental preview has no promised response time or supported production release series. [Known test limitations](docs/TESTING.md) do not imply that all issues have been identified.
